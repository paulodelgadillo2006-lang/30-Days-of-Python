# 30 Days of Python

A practical Python learning path for beginners who want to become real developers without focusing on type annotations.

This repository is designed to teach Python in plain, readable code. We will focus on:
- Python basics
- functions and data structures
- file handling
- automation
- object-oriented programming
- APIs and web basics
- Git/GitHub workflow
- mini projects and a final portfolio project

This roadmap is inspired by the idea of a 30-day challenge, but it is more realistic and project-oriented than a rushed crash course.

## How to use this repo

1. Start with Day 1.
2. Read the lesson.
3. Complete the exercises.
4. Build the mini challenge.
5. Commit your progress to GitHub.
6. Move to the next day only after you understand the current topic.

## Learning flow

- Days 1–7: Python fundamentals
- Days 8–14: logic, functions, files, and data handling
- Days 15–21: OOP, modules, and Python projects
- Days 22–30: web basics, APIs, automation, and final project

## Recommended tools

- Python 3.11+
- VS Code
- Git + GitHub
- Terminal / Bash

## Weekly mindset

Every day, practice these three things:
- Learn the concept
- Write code by hand
- Fix mistakes until it works

## Suggested study order

- Read the lesson
- Try the examples
- Write your own variation
- Solve the challenge
- Reflect: what did I learn?

## Final goal

By the end of 30 days, you should be able to:
- write clean Python scripts
- solve simple programming problems
- build small projects
- use GitHub professionally
- understand the foundations needed to become a developer

Good luck. You are building a real skill, not just memorizing syntax.

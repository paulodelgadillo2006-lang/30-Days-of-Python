# Day 1: Python Setup

## Goal
Install Python, set up your environment, and understand how Python code runs.

## What you need
- Python 3.11 or newer
- VS Code or another editor
- Terminal / command prompt

## Learn
Python is a high-level, beginner-friendly language used for:
- web development
- automation
- data science
- AI/ML
- scripting

A Python file usually ends with `.py`.

## Example
```python
print("Hello, world!")
```

## Exercise
1. Install Python.
2. Open your terminal.
3. Run:
```bash
python --version
```
4. Create a file called `hello.py`.
5. Put this inside:
```python
print("Hello, world!")
```
6. Run:
```bash
python hello.py
```

## Challenge
Write a script that prints your name and your favorite hobby.

## Notes
Your goal is not to memorize everything yet. Focus on learning how code runs and is executed.

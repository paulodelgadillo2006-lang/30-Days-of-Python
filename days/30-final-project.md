# Day 30: Final Project Build

## Goal
Create a complete project from your plan.

## Final project checklist
- has a clear purpose
- uses Python logic
- includes functions or classes
- includes some data storage or file handling
- can run from the terminal or browser
- has a README

## Example final project: To-Do App
Features:
- add task
- list tasks
- mark task as done
- save tasks to a file

## Challenge
Build your final project and upload it to GitHub.

## Final advice
This is where you move from learning Python to thinking like a developer.

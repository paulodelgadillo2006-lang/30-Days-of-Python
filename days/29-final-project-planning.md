# Day 29: Final Project Planning

## Goal
Plan a final project that demonstrates your Python skills.

## Good project ideas
- to-do app
- budget tracker
- blog backend
- recipe manager
- task scheduler
- library manager

## Steps
1. Pick a project idea.
2. Define features.
3. Write a simple plan.
4. Break it into small tasks.
5. Start building.

## Challenge
Write a project README with features and how it works.

## Notes
Good developers plan before coding.

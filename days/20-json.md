# Day 20: JSON and Data Parsing

## Goal
Understand how to work with JSON data.

## Learn
```python
import json

data = '{"name": "Ana", "age": 22}'
obj = json.loads(data)
print(obj["name"])
```

## Exercise
Parse a JSON string and print values from it.

## Challenge
Create a JSON file with your favorite books and read it with Python.

# Day 12: Sets and Comprehensions

## Goal
Learn compact and efficient ways to work with data.

## Learn
A set contains unique values.

```python
items = {"apple", "banana", "apple"}
print(items)
```

List comprehension:
```python
squares = [x * x for x in range(10)]
print(squares)
```

## Exercise
Create a list of numbers and print only the even numbers using a list comprehension.

## Challenge
Create a set of email addresses and print the number of unique emails.

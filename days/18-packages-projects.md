# Day 18: Python Packages and Project Structure

## Goal
Organize your work like a real developer.

## Example project structure
```text
project/
  app/
    __init__.py
    main.py
    helpers.py
  tests/
    test_helpers.py
```

## Exercise
Create a small project with:
- `main.py`
- `helpers.py`
- a function import

## Challenge
Build a tiny project and explain how each file helps organize logic.

## Notes
Real development is not just one file. Structure matters.

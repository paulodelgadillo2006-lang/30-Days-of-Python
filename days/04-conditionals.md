# Day 4: Conditionals and Logic

## Goal
Make decisions in your code.

## Learn
Conditionals let your script respond to different situations.

```python
age = 18

if age >= 18:
    print("Adult")
else:
    print("Minor")
```

You can use comparisons like:
- `==`
- `!=`
- `>`
- `<`
- `>=`
- `<=`

## Exercise
```python
score = 75

if score >= 70:
    print("Pass")
else:
    print("Need more work")
```

## Challenge
Ask the user for a number and print whether it is even or odd.

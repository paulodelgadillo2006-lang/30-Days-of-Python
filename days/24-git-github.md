# Day 24: Git and GitHub Workflow

## Goal
Learn how to save and share code using Git.

## Basic commands
```bash
git init
git add .
git commit -m "Initial commit"
git branch -M main
git remote add origin <url>
git push -u origin main
```

## Exercise
Create a GitHub repository and push your code there.

## Challenge
Create a second file, commit it, and push the changes.

## Notes
Version control is essential for every real developer.

# Day 11: Built-in Functions and List Tricks

## Goal
Use common Python built-ins more effectively.

## Learn
```python
numbers = [2, 5, 8, 1]
print(len(numbers))
print(max(numbers))
print(min(numbers))
print(sum(numbers))
```

## Exercise
```python
words = ["apple", "banana", "orange"]
print(sorted(words))
```

## Challenge
Write a script that gets the longest word in a list and prints it.

## Notes
The more comfortable you are with built-ins, the faster you become as a developer.

# Day 6: Dictionaries and Tuples

## Goal
Learn structured data types.

## Learn
A dictionary stores key-value pairs.

```python
student = {
    "name": "Luis",
    "age": 22,
    "course": "Python"
}

print(student["name"])
```

A tuple is similar to a list but cannot be changed.

```python
point = (10, 20)
print(point[0])
```

## Exercise
```python
person = {
    "name": "Sara",
    "city": "Mexico",
    "email": "sara@example.com"
}

print(person["city"])
```

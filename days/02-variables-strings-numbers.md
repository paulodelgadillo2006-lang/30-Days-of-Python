# Day 2: Variables, Strings, and Numbers

## Goal
Learn how to store and use data in Python.

## Learn
Variables hold values. Python does not require type declarations.

```python
name = "Alice"
age = 25
height = 1.68
```

Strings are text. Numbers can be integers or floats.

```python
message = "Hello"
print(message)
print(message + " world")
```

## Exercise
```python
name = "Sam"
print(name)

age = 20
print(age)

price = 9.99
print(price)
```

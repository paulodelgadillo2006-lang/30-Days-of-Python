# Day 5: Functions

## Goal
Learn reusable code blocks.

## Learn
Functions save time and reduce repetition.

```python
def greet(name):
    return "Hello, " + name

print(greet("Ana"))
```

## Exercise
```python
def square(number):
    return number * number

print(square(4))
```

## Challenge
Write a function that adds two numbers and returns the result.

## Practice
Try this:
```python
def is_even(number):
    if number % 2 == 0:
        return True
    return False

print(is_even(10))
```

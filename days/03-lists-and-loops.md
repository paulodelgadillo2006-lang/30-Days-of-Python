# Day 3: Lists and Loops

## Goal
Understand how to store multiple values and repeat work.

## Learn
A list is an ordered collection.

```python
colors = ["red", "blue", "green"]
print(colors[0])
```

A loop helps you repeat actions.

```python
for color in colors:
    print(color)
```

## Exercise
```python
numbers = [1, 2, 3, 4, 5]
for number in numbers:
    print(number * 2)
```

## Challenge
Create a list of your favorite foods and print each one with a message.

## Bonus
Practice using `range()`:
```python
for i in range(5):
    print(i)
```
